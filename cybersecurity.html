SECURITY, CONSIDERED

Build safer habits
and foundations.

Security needs vary by organisation. Work is discussed and agreed in advance, including scope, permissions and limitations. No system is represented as completely secure.

01 / AWARENESS

Security awareness

Discuss everyday practices for accounts, information handling and recognising suspicious activity.

02 / WEBSITE

Website security guidance

Review general website configuration and discuss practical hardening and maintenance considerations.

03 / ASSESSMENT

Basic security review

Consider a limited, non-invasive review only after written authorisation and an agreed scope.

04 / BUILD

Secure development guidance

Include privacy and security considerations in website and application planning.

WHAT TO EXPECT

Defensive guidance,
clearly bounded.

01 / POSSIBLE DELIVERABLES

Actionable review notes

  • Agreed awareness or website-security review
  • Prioritised observations and practical recommendations
  • Written scope, limitations and close-out summary
02 / PROCESS

Authorise, scope, review

  • Confirm ownership, written permission and contacts
  • Agree permitted methods, boundaries and schedule
  • Discuss observations and agreed next steps
03 / CLIENT INPUTS

Confirm authority and context

  • Proof of authority to request the work
  • Defined websites, systems or awareness goals
  • Technical contact, constraints and escalation contact
